# Production Tracking Auditor Skill

## Overview
Monitors shop-floor workstation telemetry in real time, computes Availability, Performance, and Quality metrics, and generates OEE reports.

## Operations
1. Ingests cycle pulses and calculates real-time workstation speeds.
2. Compares actual cycle times against standard technology routing times.
3. Computes OEE percentage and flags throughput bottlenecks.
