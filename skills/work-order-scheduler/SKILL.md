# Work Order Scheduler Skill

## Overview
Sequences production orders based on delivery deadlines, tooling availability, and material constraints.

## Operations
1. Ingests queued work orders and required Bill of Materials (BOM).
2. Optimizes machine allocations using Gantt scheduling principles.
3. Formulates daily dispatch lists for shift supervisors.
