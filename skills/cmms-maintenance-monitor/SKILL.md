# CMMS Maintenance Monitor Skill

## Overview
Monitors operating hours and stroke counts to prevent unexpected machine failure and manage spare part stock.

## Operations
1. Tracks cumulative run hours against manufacturer recommended service intervals.
2. Flags machinery approaching 85% of rated tooling cycle life.
3. Generates preventative maintenance work requests for engineering teams.
